## ADDED Requirements

### Requirement: Getting started uses Profile for humans
`GETTING_STARTED.md` and the methodology `AGENTS.md` template SHALL describe assessment tracks as **profiles** for methodologists; examples MUST use `--profile` / profile create language, not Role as a Specra entity.

#### Scenario: Human-facing intent examples say profile
- **WHEN** a non-developer reads getting-started / init `AGENTS.md`
- **THEN** they see «профиль» / Profile examples (e.g. Java backend) without being taught to create a Specra Role
